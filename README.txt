CLAUDE VPN GUARD 0.2.0

Windows 10/11 x64, .NET Framework 4.8, Claude Desktop из Microsoft Store.

Установка: Install.cmd. Запуск Claude: ярлык «Claude VPN».
Удаление: Remove.cmd. Настройки: правый щелчок по значку защиты в трее.
После установки утилита запускается при входе пользователя в Windows.

VPN: v2RayTun, MantaRay и другие TUN/TAP-клиенты. По умолчанию включено
автоопределение драйверов sing-tun, Wintun, WireGuard, TAP-Windows, MantaRay.
Также можно перечислить точные имена адаптеров через ; в настройках.
Нужен режим полного туннеля; одного системного прокси недостаточно.

Утилита проверяет адаптер, маршруты IPv4 и TLS-соединение с claude.ai.
Без подтверждённого VPN запуск через ярлык блокируется. Уже открытый Claude
получает 10 секунд на восстановление VPN (настраивается от 5 до 10 секунд).
При переключении VPN новый туннель проверяется заново.

Это контроль приложения, а не сетевой kill switch. Обычный ярлык Claude
может кратко открыть процесс до его обнаружения. На время допуска сеть
не блокируется. Принудительное закрытие может потерять несохранённый ввод.
Если адаптер остаётся включённым, время обнаружения сбоя соединения
(обычно до 5 секунд) добавляется к допуску. Длительные сбои DNS, интернета
или TLS также приводят к закрытию Claude. IPv6 и правила внутри VPN
не контролируются. Отдельно запущенный Claude Code не отслеживается.

Для контроля утилита должна работать. Выход из трея прекращает защиту.
Настройки и журнал: %LOCALAPPDATA%\ClaudeVpnGuard.
Конфигурации VPN и переписка не читаются; телеметрии нет.
